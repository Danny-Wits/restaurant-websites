# Aroma Multi Cuisine Restaurant — Channi Himmat, Jammu

> **The Grand Symphony of Saffron, Smoke & Celebration**  
> Luxury Tier 2 React + Vite + Tailwind CSS production-grade website for Jammu's premier multi-cuisine sanctuary.

---

## 🏛️ Project Overview

- **Location**: Plot 14-A, Commercial Belt, Near Main Marble Market Road, Sector 1, Channi Himmat, Jammu – 180015 (Off NH-44, 3 mins from Bahu Plaza & Wave Mall)
- **Tech Stack**: React 19 + Vite 8 + Tailwind CSS v4 + Lucide React
- **Culinary Disciplines**: Authentic Kashmiri Wazwan, Royal Charcoal Tandoor, Indo-Chinese Wok Artistry, Artisanal Cast-Iron Sizzlers, and Traditional Kehwa & Desserts.

## 🚀 Key Features & Components

1. **`Navbar`**:
   - Sticky glassmorphic bar with backdrop blur
   - Saffron flame brand logo with Jammu subtitle
   - Direct phone call trigger (`+91 191 246 8899`)
   - "Reserve Table" CTA button
   - Responsive mobile hamburger drawer

2. **`Hero`**:
   - Atmosphere with ambient golden lighting and high-contrast dark palette
   - Live restaurant status pill (dynamic Indian Standard Time check: Lunch 12:30–4:00 PM | Dinner 7:00–11:30 PM | Kitchen Cutoff 11:00 PM)
   - Dual luxury eyebrow badges
   - Quick stats grid (40+ dishes, 100% charcoal tandoor, Wazwan master ustads, 4.8★ reviews)

3. **`PillarsBanner`**:
   - Strictly Segregated Pure Veg & Wazwan stations (Dogra & Kashmiri family assurance)
   - 100% Kishtwar Saffron & Valley Cockscomb (Mawal) provenance
   - Fired exclusively by natural charcoal in clay tandoors
   - Private Dining Room (PDR for 35 guests) & VIP Valet Parking

4. **`HeritageStory`**:
   - Story of Jammu's Mehmaan-Nawaazi and slow brass degh cooking
   - Executive Chef Ghulam Mohiuddin quote & craft notes
   - Visual mosaic featuring copper deghs and live brass Kehwa samovars

5. **`ChefSpecials` (Spotlight)**:
   - Kashmiri Mutton Rogan Josh (slow-simmered in mawal flower extract)
   - Awadhi Galouti Kebab with Ulte Tawe Ka Paratha (32 potli spices)
   - Aroma Signature Cottage Cheese Sizzler (280°C hissing cast iron)
   - Shahi Kesari Phirni in Clay Kasora (earthen pot setting)

6. **`InteractiveMenu`**:
   - Sticky horizontal category pill bar with smooth scrolling across 6 categories (44 total dishes)
   - Instant live search input (matches dish names, ingredients, descriptions, tags)
   - Dietary filter toggles: All Dishes, Pure Veg 🟢, Non-Veg 🔴, Chef's Signature ⭐
   - Spice level indicators (chillies 0 to 3)
   - Detailed dish cards with prices in ₹, dietary tags, and click-to-view trigger

7. **`DishDetailModal`**:
   - Comprehensive dish inspection dialog
   - Full botanical ingredients breakdown
   - Curated drink and bread pairings
   - Spice intensity rating with explanation
   - Ustads' secret craft notes
   - Instant table reservation trigger

8. **`ReservationModal`**:
   - Multi-step interactive table booking flow
   - Date picker, Lunch/Dinner meal service toggles
   - 6 guest party tiers (from solo executive to 35-guest Imperial PDR)
   - 4 seating sections (Royal Chandelier Hall, Imperial PDR, Candlelight Corner, Live Tandoor View)
   - Dedicated pure vegetarian kitchen flag checkbox
   - Instant booking confirmation with reference ID (`ARM-2026-XXXX`) and valet directions

9. **`Testimonials`**:
   - Verified local Jammu diner testimonials (Bahu Plaza tech executives, Channi Himmat families, Gandhi Nagar connoisseurs, Katra pilgrims)
   - 4.8★ Google aggregate rating badge

10. **`LocationAndHours`**:
    - Complete address, landmarks, and timings
    - Direct Google Maps navigation trigger
    - Direct phone & WhatsApp concierge triggers
    - Stylized map card

11. **`MobileActionBar`**:
    - Fixed bottom thumb-friendly navigation bar on mobile (<768px):
      - [📞 Call]
      - [📖 Menu]
      - [🗺️ Map Directions]
      - [📅 Reserve Table]

12. **`Footer`**:
    - Brand identity, dining hall amenities, quick links, contact details, and copyright

## 🛠️ Development & Production

To run locally in development mode:
```bash
cd restaurant-workspace/aroma-channi-himmat
npm run dev
```

To build for production:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
